---
description: Create a new Architecture Decision Record (ADR)
---

Create a new ADR in `docs/01-design/decisions/`.

Steps:
1. Find the next number by listing existing files in `docs/01-design/decisions/` (numbered like `0001-`, `0002-`, etc.). Use the next sequential number.
2. Ask me for the decision title if not given.
3. Create the file using the template at `docs/01-design/decisions/0000-template.md`.
4. Fill in: title, date (today), status (Proposed), and stub sections for Context, Decision, Consequences.
5. Show me the file path when done.

Filename format: `NNNN-kebab-case-title.md` (e.g., `0007-use-postgres-over-mongo.md`).

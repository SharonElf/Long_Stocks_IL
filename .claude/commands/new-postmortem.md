---
description: Create a new postmortem after an incident
---

Create a new postmortem in `docs/07-debug/postmortems/`.

Steps:
1. Find the next number by listing existing postmortems. Use the next sequential number.
2. Ask me for: incident title, date the incident occurred, and a one-line summary.
3. Use the template at `docs/07-debug/postmortems/0000-template.md`.
4. Fill in the metadata; leave the timeline/root cause/action items sections as prompts for me to fill in.
5. Show me the file path when done.

Filename format: `NNNN-YYYY-MM-DD-kebab-case-title.md`.

Remind me that postmortems are blameless — focus on systems and processes, not people.

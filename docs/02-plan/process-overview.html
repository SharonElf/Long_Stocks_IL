Long Stocks IL: how it works

The process as decided so far. Draft, revision 2, 2026-10-08. Nothing is built yet.

The idea in one minute
  • Every day, after the market closes, the system researches each ticker the investor holds.
  • The ticker's own trend decides. Each ticker gets one stance and a reason.
  • Once a week the system also reads the mood of the whole market, as background.
  • No amounts for now. "Add" and "reduce" say what and why, not how much.
  • It only gives advice. It never buys or sells by itself.
  • Long only. No shorts, ever. "Sell all" is the lowest it goes.
HoldDo nothing
AddLooks good enough to buy more
ReduceLooks weak enough to sell some
Sell allClose the position

"Replace" is not a stance. That choice stays with the investor. The system only needs data for what is already held.

3. Long charts first, short charts only if flagged

This split keeps small noise out of the decisions.

Scanner

Charts: monthly, weekly, daily

Job: raise a flag when a ticker enters a danger zone or an opportunity zone.

Runs: every day on every ticker.

Fine-tune

Charts: 4 hours, 1 hour

Job: sharpen the timing, but only after the scanner flagged something.

Not for: mutual funds and bonds (one price per day).

4. Next stage: the whole portfolio

Parked on purpose. The single ticker matters more than the portfolio as a whole, so this comes later.

Not part of this stage
  • How much to add or reduce, and the money amount.
  • Risk groups (low, medium, high) and which holding belongs to which. The investor will supply the table.
  • Target share per group. The call's example was 22% / 60% / 18%, and the investor said the real table is "a little more complicated".
  • The gap between real and target shares, and a safe zone where the system says nothing.
  • Where cash belongs.
  • Comparing tickers with each other.

5. What is decided, and what is not

Decided (draft)

  • Risk and trend are judged per ticker
  • Four stances: hold, add, reduce, sell all
  • No amounts for now
  • Long only, no shorts ever
  • Tickers checked daily
  • Market sentiment read weekly
  • Long charts first, short charts only if flagged
  • Advice only, no automatic orders (to confirm)
  • Tools: n8n, Claude API, Supabase
  • All calculations happen in Supabase, before Claude
  • n8n only conducts, it holds no business rules
  • Claude never does maths or reads raw charts
  • Everything is logged and can be replayed
  • Data budget about $50 to $100 a month

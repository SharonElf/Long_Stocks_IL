# Postmortems

After every notable incident, write one. Even small ones — the practice compounds.

## Rules

- **Blameless.** Focus on systems and processes, not individuals. "The deploy script didn't validate X" not "Alice didn't validate X".
- **Honest.** If the root cause is "we hadn't thought about this," say so. If it's "we knew but deprioritized," say that too.
- **Action items have owners and due dates.** Otherwise nothing changes.
- **Postmortems are never edited after publication.** New info? New postmortem.

## Format

Use `/new-postmortem` or copy `0000-template.md`.
